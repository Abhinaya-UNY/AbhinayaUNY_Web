## BAGIAN 1: Ringkasan Eksekutif & Metodologi Verifikasi PDDikti

### 1.1. Latar Belakang & Mandat Integritas

Tim Robotika **Abhinaya UNY** adalah divisi robotika di bawah naungan Unit Kegiatan Mahasiswa (UKM) Rekayasa Teknologi (Restek) Universitas Negeri Yogyakarta yang didedikasikan secara khusus untuk bertanding dalam ajang bergengsi **Kontes Robot Tematik Indonesia (KRTMI)** yang diselenggarakan oleh Pusat Prestasi Nasional (Puspresnas) / Balai Pengembangan Talenta Indonesia (BPTI) Kemendikbudristek RI, serta kompetisi transporter robotika nasional seperti **Technocorner Universitas Gadjah Mada (UGM)**.

Dokumen ini disusun sebagai acuan tunggal dan definitif (*single source of truth*) yang memadukan analisis komputer visual mendalam terhadap ratusan foto feed Instagram `@abhinaya.uny`, audit berkas fisik di repositori, serta verifikasi silang 100% terhadap basis data Pangkalan Data Pendidikan Tinggi (PDDikti) Kemendikbudristek. Seluruh data anggota, riwayat kepemimpinan, nomor induk mahasiswa (NIM), program studi, fakultas, dan keterikatan foto telah dibersihkan dari nilai placeholder, kekeliruan scraper, atau duplikasi identitas.

### 1.2. Arsitektur & Dekodifikasi Format 11 Digit NIM UNY

Nomor Induk Mahasiswa (NIM) di Universitas Negeri Yogyakarta memiliki struktur hierarkis deterministik 11 digit angka. Formula pembentukan NIM adalah:

$$\text{NIM} = \underbrace{\text{AA}}_{1-2} \ \underbrace{\text{F}}_{3} \ \underbrace{\text{PP}}_{4-5} \ \underbrace{\text{JJ}}_{6-7} \ \underbrace{\text{K}}_{8} \ \underbrace{\text{NNN}}_{9-11}$$

#### Rincian Struktur Komponen:
1. **Digit 1–2 ($\text{AA}$): Tahun Angkatan Masuk Mahasiswa**
   - `17` = Angkatan Masuk 2017
   - `18` = Angkatan Masuk 2018
   - `19` = Angkatan Masuk 2019
   - `20` = Angkatan Masuk 2020
   - `21` = Angkatan Masuk 2021
   - `22` = Angkatan Masuk 2022
   - `23` = Angkatan Masuk 2023
   - `24` = Angkatan Masuk 2024
2. **Digit 3 ($\text{F}$): Fakultas / Jenjang Pendidikan**
   - `5` = Fakultas Teknik (FT) untuk Program Sarjana (S1)
   - `3` = Fakultas Matematika dan Ilmu Pengetahuan Alam (FMIPA) untuk Program Sarjana (S1)
   - `0` / `507` = Fakultas Vokasi (FV) / Program Sarjana Terapan (Diploma IV)
3. **Digit 4–5 ($\text{PP}$): Kode Program Studi Resmi**
   - **Fakultas Teknik (FT):**
     - `01` $\rightarrow$ Pendidikan Teknik Elektro (Kode PDDikti FT: `501`)
     - `02` $\rightarrow$ Pendidikan Teknik Elektronika (Kode PDDikti FT: `502`)
     - `03` $\rightarrow$ Pendidikan Teknik Mesin (Kode PDDikti FT: `503`)
     - `04` $\rightarrow$ Pendidikan Teknik Bangunan / Sipil (Kode PDDikti FT: `504`)
     - `18` $\rightarrow$ Pendidikan Teknik Mekatronika (Kode PDDikti FT: `518`)
     - `38` $\rightarrow$ Teknik Elektro [Murni / Non-Kependidikan] (Kode PDDikti FT: `538`)
     - `39` $\rightarrow$ Teknik Manufaktur [Murni / Non-Kependidikan] (Kode PDDikti FT: `539`)
     - `40` $\rightarrow$ Teknik Mesin [Murni / Non-Kependidikan] (Kode PDDikti FT: `540`)
   - **Fakultas MIPA (FMIPA):**
     - `06` $\rightarrow$ Fisika [Murni] (Kode PDDikti FMIPA: `306`)
   - **Fakultas Vokasi (FV):**
     - `50733` $\rightarrow$ D4 Teknik Elektronika (Era FT/Diploma)
     - `50734` $\rightarrow$ D4 Teknik Mesin (Era FT/Diploma)
     - `09062` $\rightarrow$ D4 Teknik Elektronika (Era Fakultas Vokasi Kampus Wates)
4. **Digit 6–7 ($\text{JJ}$): Jenjang & Nomenklatur Gelar**
   - `24` = Program S1 Kependidikan (Gelar Kelulusan: Sarjana Pendidikan / S.Pd.)
   - `14` = Program S1 Non-Kependidikan / Ilmu Murni & Teknik (Gelar Kelulusan: Sarjana Teknik / S.T. atau Sarjana Sains / S.Si.)
   - `33` / `34` / `20` = Program Diploma IV / Sarjana Terapan (Gelar Kelulusan: Sarjana Terapan Teknik / S.Tr.T.)
5. **Digit 8 ($\text{K}$): Jalur Masuk & Tipe Kelas Rombel**
   - `1` = Kelas Reguler (SNBP/SNMPTN, SNBT/SBMPTN, Seleksi Mandiri Reguler UNY)
   - `4` = Kelas Kerjasama / Alih Jalur / Mandiri Khusus
6. **Digit 9–11 ($\text{NNN}$): Nomor Urut Presensi Mahasiswa**
   - Nomor urut registrasi mahasiswa dalam satu rombongan angkatan dan prodi (misal: `001` hingga `100+`).
