## 🛠️ 4 Divisi di Tim Abhinaya UNY
1. **Divisi Mekanik**: 3D CAD Modeling, chassis assembly, CNC & 3D printing gripper.
2. **Divisi Elektrik & Hardware**: PCB design, motor drivers arus tinggi, power management baterai LiFePO4, sensor fusi.
3. **Divisi Pemrograman & AI**: Embedded C/C++ firmware, navigasi otonom, kamera AI YOLO deteksi objek.
4. **Divisi Manajerial & Media**: Project management, dokumentasi video/foto, branding media sosial Instagram & TikTok.
