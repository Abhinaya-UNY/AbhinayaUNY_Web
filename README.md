## ⚡ Teknologi & Arsitektur Robot
* **Kinematika Invers**: 4-Wheel Mecanum Holonomic Drivetrain & 3-Wheel Omni Drive dengan komputasi matriks invers $100\text{ Hz}$.
* **Embedded & Kendali**: Dual-Core ESP32-S3 + STM32 ARM Cortex-M4 dengan FreeRTOS dan Closed-Loop PID Velocity Tracking.
* **Visi Komputer / Edge AI**: Real-time Object Detection & Spatial Depth Localization (YOLOv8/11 + OpenCV).
* **Mekanik & Gripper**: Struktur modular alumunium alloy, lead screw ganda, dan capit bertenaga torsi tinggi.

---

## 💻 Tech Stack Website
* **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Export)
* **Bahasa**: TypeScript
* **Styling**: Tailwind CSS (Cyberpunk Dark Neon Theme)
* **Icons**: Lucide React
* **Deployment**: GitHub Pages via GitHub Actions (`deploy.yml`)

---

## 🛠️ Menjalankan Lokal

```bash
# Clone repository
git clone https://github.com/Abhinaya-UNY/AbhinayaUNY_Web.git
cd AbhinayaUNY_Web

# Install dependencies
npm install

# Jalankan server pengembangan
npm run dev

# Build untuk static export
npm run build
```
